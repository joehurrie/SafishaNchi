## What I Do
- Integrate declarative, state-linked UI animations using `motion` wrappers.
- Enforce hardware-accelerated animations using native Web Animation APIs and ScrollTimeline.
- Handle multi-surface app gestures (tap, drag, hover) cross-device.

## When to Use Me
Use this skill when components require smooth visual entry, exit, page transitions, scroll-linked parallax effects, or spring-physics mechanics.

## Core Directives
1. Use the declarative `<motion.div>` pattern instead of messy raw timeline code.
2. Prefer spring-based physics over rigid duration easing for natural, clean look-and-feel.
3. Automatically execute `npm install framer-motion` (or `motion`) if missing from package.json.
