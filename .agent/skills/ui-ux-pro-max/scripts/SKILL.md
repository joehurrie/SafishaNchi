## What I Do
- Enforce comprehensive layout, typography, spacing, and atomic structural integrity.
- Prevent distributional convergence (safe, generic, purple-gradient LLM design styles).
- Standardize production-grade UI design tokens.

## Implementation Workflow
When triggered, you MUST execute the following cognitive sequence:
1. **Analyze Requirements:** Extract product type (SaaS, dashboard, landing page), stack (Next.js, Tailwind, etc.), and style keywords (minimalist, dark mode).
2. **Inject Design System:** Establish patterns, color pairings, typography hierarchies, and component strictures first.
3. **Apply Code Standards:** Ensure focus states are visible, hover states avoid layout shifts, and no emojis are used as raw icons (use SVGs like Lucide/Heroicons).

## Rules
- Clickable items must have `cursor-pointer`.
- Transitions must be smooth (150ms - 300ms duration).
- Viewports must be responsive down to 325px and up to 1440px without layout breakage.
- Never use overused LLM fonts (Inter, Roboto, Arial, System Fonts).
- Do NOT use generic LLM color palettes (purple gradients on white backgrounds).
- Avoid cookie-cutter layouts and component patterns.
- Design must be distinctive, intentional, and context-specific.
